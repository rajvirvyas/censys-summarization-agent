# Censys Host Data Summarization Agent 
This project was built for Censys' 2026 AI Intern Take-Home Assignment. It is an AI-powered tool which provides a human-readable, security-focused summary of raw [Censys](https://censys.com/) JSON host scan data. To do this, I harnessed the power of the LlaMA 3 large language model (LLM) using Groq for the API to provide a fast, modern experience.
